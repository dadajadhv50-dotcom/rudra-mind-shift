RUDRA MIND SHIFT — GitHub पर अपलोड करने का तरीका

1. ZIP डाउनलोड करके मोबाइल में Extract/Unzip करें।
2. ZIP के अंदर RUDRA_MIND_SHIFT_GitHub फ़ोल्डर की सभी फाइलें मिलेंगी।
3. github.com खोलें और नया repository बनाएँ: rudra-mind-shift
4. Repository में Add file → Upload files चुनें।
5. Extract किए गए फ़ोल्डर के अंदर की सभी फाइलें और .github फ़ोल्डर अपलोड करें। केवल ZIP फाइल अपलोड न करें।
6. Commit changes दबाएँ।
7. Settings → Pages में Source को GitHub Actions चुनें।
8. Actions टैब में deployment पूरा होने का इंतजार करें। सफल होने पर वेबसाइट का URL मिलेगा।

ध्यान दें:
- यह GitHub पर डालने योग्य पूरा वेब गेम/PWA प्रोजेक्ट है, Android APK नहीं।
- Online leaderboard, login, cloud save और multiplayer अभी जुड़े नहीं हैं।
- पहली बार HTTPS वेबसाइट खुलने के बाद supported browser में offline cache काम कर सकता है।
